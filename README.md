# Artificial Intelligence — 60-Day Challenge Track

A structured, day-by-day journey through AI fundamentals to practical application, 
completed as part of the AB Talks 60-Day Challenge.

## 🎯 Goal
Build a solid foundation in AI/ML concepts and ship a working project by Day 60.

## 🗺️ Roadmap

| Phase | Days | Focus |
|-------|------|-------|
| Foundations | 1–15 | AI/ML/DL basics, math prerequisites, key terminology |
| Core Techniques | 16–35 | Regression, classification, neural networks, intro NLP/CV |
| Tools & Frameworks | 36–50 | Python, scikit-learn, TensorFlow/PyTorch |
| Capstone Project | 51–60 | Build & present a real AI project |
